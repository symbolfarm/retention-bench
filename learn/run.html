What the toy omits

The real run is stricter

Fresh directories

Each real P, C, and R arm starts from a separate empty survive-directory, so state cannot leak between arms.

Every task instance

P, C, and R play the identical deterministic instance schedule. Their scores are means over those outcomes, not hand-picked probes.

Uncertainty and windows

The real curve carries bootstrap intervals and W(m), the first instances after each reset, to distinguish retention from fast relearning.
