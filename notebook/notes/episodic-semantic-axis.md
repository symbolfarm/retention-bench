# The episodic→semantic axis

**The probe ladder measures one quantity: how much of the answer had to become
semantic memory rather than remain episodic.**

Previously stated as "how far the probe sits from the surface form of what was
taught." That is the observable proxy; this is the underlying quantity. Recall
asks only that the episode survived; each rung above asks for something no single
episode contains.

| Probe family | What it asks | Episodic→semantic distance |
|---|---|---|
| Recall | restates the taught form | zero — the episode suffices |
| Composition | join two taught items | must relate episodes |
| Aggregation / absence | a property of the whole set | must abstract over all episodes |
| Revision | which of two taught items is current | must order episodes and discard one |
| Application | apply a run-learned procedure to a new input | the procedure must have become semantic |

## Read the profile, not the level

Corollary of [recording vs memory](recording-vs-memory.md), and the most
actionable thing to come out of the 2026-08-02 session:

**A perfect score on Recall is not by itself good news.** Verbatim fidelity is
what a recording is *for*. Human episodic memory is notoriously inaccurate and the
inaccuracy is the signature of compression into a structure — the same compression
the upper rungs depend on.

| Profile across rungs | Reading |
|---|---|
| high recall, cliff immediately above | a recording |
| moderate recall, graded decline with distance | a memory |
| flat at chance | nothing retained |

This is a discriminating prediction available from measurements we can nearly take
already, and it costs no code — it is how the ladder is read and presented.

Guard: we do **not** claim reconstruction is *required*. That would be an argument
from human architecture and the instrument is substrate-neutral. If a system clears
every rung on a verbatim log, the claim is refuted and we report it.

## Distance-based scoring generalises

The ROADMAP's note that aggregation should be scored by distance rather than exact
match ("a system that reconstructs *about forty* when the answer is forty-two has
done something real") predates this framing but follows from it. It is not special
pleading for one rung — it follows from what a memory is. Expect the same argument
to apply wherever a rung's output is a compressed quantity.
