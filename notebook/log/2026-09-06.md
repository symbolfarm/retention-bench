# 2026-09-06

## Session — first real LLM measurement (RB-19)

Built an iterative-retrieval SUT that stores the widened associative curriculum
in the survive-dir, performs a dependent object→attribute→bin lookup chain, and
then asks the pinned LLM for a schema-conforming answer. It ran through the real
`SubprocessSystem` path with a hard process kill after all 48 training items.

The first paid pilot used only 32 completion tokens. The model's hidden reasoning
consumed that budget and 168/192 replies were malformed; the pilot is retained
but rejected as capability evidence. Raising the completion budget to 256 left
four malformed replies in the final run.

The final run answered 32/32 transfer probes and 16/16 held-out transfer probes
with an intact store, both with and without the process kill. The wiped-store
prior answered 0/32. So iterative retrieval closes the instrument's current
two-hop gap. That sharpens rather than settles the thesis: the only composition
rung is now too low to separate retrieval from consolidation. The independent
stochastic arms also made `R/C > 1` (`norm_gain 1.033`), demonstrating that a
single API run is a dated observation rather than a stable reference rung.

Final-run provider-reported cost was US$0.014782495432. Including the retained
pilot and development probes, task spend is conservatively bounded below
US$0.025 against the authorized US$1 cap.
